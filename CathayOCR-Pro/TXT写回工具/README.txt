# TXT文本层写回工具 v1.1

## 它是什么

一个**批量修复「双层 PDF 无法搜索」问题的独立小工具**。

很多古籍 PDF（网上下载或旧工具生成）带有**错误/无法搜索的隐藏文本层**——
用 Chrome/Edge 打开时 Ctrl+F 搜不到字，但同名的 `_result.txt` / `_PD6AIFOCR.txt`
里却有完整 OCR 文字。

本工具把 TXT 里的识别结果**按页码重新写回 PDF**，替换掉错误的旧文字层，
让 PDF 重新可搜索、可复制。

## 核心特点

- **按页码对应**：TXT「第 N 页」的内容写入 PDF 第 N 页，不依赖图像坐标
- **竖排古籍风格**：每页文字从右上角起，每行一列，列从右到左（rotate=270），符合古籍版式
- **透明文字层**：不影响看图，可正常复制/搜索
- **彻底清除旧层**：删除内容流中全部旧文字（含残留 TD 块），图像层像素级无损
- **多核并行** ⭐：默认 4 线程同时处理，可调 1~16，处理 400+ 文件大幅提速
- **递归扫描** ⭐：选任意父目录，自动扫描所有子目录配对
- **保留原件**：输出 `XXX_..._fixed.pdf`，不覆盖原文件
- **任意页面尺寸**：列宽/字号按页面尺寸动态计算，兼容 A4 与其它开本

## 支持的文件配对

自动识别以下三种后缀配对（其它后缀如 `_FOCR_opt.txt`、`_【繁转简】` 一律忽略）：

| TXT | PDF | 来源 |
|---|---|---|
| `XXX_result.txt` | `XXX_layered.pdf` | CathayOCR Lite 输出 |
| `XXX_PD6AIFOCR.txt` | `XXX_PD6AIFOCR_opt.pdf` | FOCR 工具输出 |
| `XXX_PD6AIFOCR.txt` | `XXX_PD6AIFOCR.pdf` | FOCR 无 _opt 变体（如北洋政府公报） |

## 运行方法

双击 `启动工具.bat`，或命令行执行：

```
D:\我的软件创作库\Cathay OCR Lite\portapython\python.exe gui_main.py
```

## 使用步骤

1. 点 **选择目录**，选中存放配对文件的**任意父目录**（会自动递归扫描所有子目录）
2. 列表会显示配对的两个文件名（TXT 列 + PDF 列）与状态
3. （可选）修改输出后缀，默认 `_fixed`；调整「并行数」（默认 4，可调 1~16）
4. 点 **开始处理选中项**，等待完成
5. 输出文件在各 PDF 同目录下生成 `XXX_..._fixed.pdf`，在 Chrome/Edge 中打开即可搜索

## 命令行模式（可选）

```
python txt_layer_writer.py <result.txt> <layered.pdf> [后缀]
```

## 文件说明

- `gui_main.py` — 图形界面主程序（递归扫描、多核并行）
- `txt_layer_writer.py` — 核心处理模块（解析 TXT、清旧层、竖排写入）
- `启动工具.bat` — 双击启动 GUI
- `README.txt` — 本说明

## 注意事项

- TXT 与 PDF 必须同名前缀且后缀符合上表配对规则
- TXT 中的 `=====` 分隔线会被自动过滤，不写入 PDF
- 若某页 TXT 无内容，该页跳过（保留原状）
- 并行数不建议超过 CPU 核数；内存较小的大文件场景可适当降低并行数
- 处理前建议先小范围试跑（2~3 对文件）确认效果
