# CathayOCR Lite (轻量版) v1.3.5

基于 ncnn Vulkan 的便携式 PDF OCR 工具。CathayOCR 专业版的轻量分支。

## 特性亮点

🚀 **单一引擎，一键启动**
- 仅保留 ncnn Vulkan 引擎，无需选择纠结
- GPU 模式（Vulkan 加速）/ CPU 模式（原生 ncnn，不初始化 Vulkan）
- 支持任意品牌显卡：NVIDIA / AMD / Intel 均可
- 支持 PP-OCR 多版本模型（v3 ~ v6，共 7 个模型）

📦 **极致便携，U 盘即用**
- 体积约 1.4GB，原始版 9GB 的 1/6
- 自带便携 Python 环境，无需任何安装
- 拷贝到任意目录即可运行

🌍 **多语言支持**
- 直接可选：中文（繁简体自动识别）、English、Français、Deutsch、日本語、Español、Italiano、Português、Nederlands、Polski、Magyar、Čeština、Ελληνικά（希腊文）、Tiếng Việt（越南文）
- 轻量版字典不含、下拉中**灰色不可选**（需专业版）：韩文、俄文等西里尔文系、阿拉伯文系、天城文系、泰文、泰卢固文、泰米尔文
- 语言列表会随所选模型自动刷新（不同模型的字典覆盖能力不同）

📄 **PDF OCR 专业功能**
- GPU 双实例并行（提升 30~50%）
- 古籍/竖排/复杂排版支持
- 拖放文件处理，批量输出
- **输出目录默认 = 每个 PDF 自己所在的文件夹**（也可指定统一输出目录）

🛡️ **出错时「宁可重跑，也绝不悄悄少页」**（v1.3.1）
- 某页识别失败 → 自动**重试该页** → 仍失败 → **整份文件重处理一遍** → 仍失败才报错
- 并会在源文件目录写一份 `{文件名}_OCR未完成警告.txt`，让你一眼看出哪本没跑完
- 绝不会出现「结果悄悄少了几页却看不出来」的情况

🪟 **迷你窗口模式**（v1.3.1）
- 处理中把主窗口与日志窗口一起收成右下角一张小卡片，边看书边等它跑
- 卡片可拖动、可切换置顶，处理完成自动还原

📝 **运行日志落盘**（v1.3.1）
- 全部运行输出按天写到 `logs\` 目录，出问题随时可查

🩺 **GPU 卡死 / 大量空白？一键修复**（v1.3.4）
- **现象**：跑一阵后导出的文件大量空白，或日志反复刷 `[自动恢复] 重建引擎`
- **原因**：**Windows 的 GPU 超时看门狗（TDR）默认只给 2 秒**——超时就把显卡驱动重置，OCR 引擎手里的显卡设备随之作废（进程还在，但每页都算不出来）
- **修复**：双击本目录 **`GPU卡死修复_调大TDR超时_需重启.reg`** → 弹窗点「是」→ **重启电脑**（想还原双击 `GPU卡死修复_还原TDR超时_需重启.reg`）
- **加码**：专业模式「精度」选 **`FP16 (快速)`**，单次 GPU 计算量大幅下降、更难撞线（**AMD 核显保持 FP32**）
- **兜底**：v1.3.4 起即使撞上，程序也会自动**重建引擎 + 重跑本页**，**绝不把「算不出来」当成「这页空白」交付**

## 系统要求

- **操作系统**：Windows 7/10/11 64位
- **GPU 模式**：支持 Vulkan 1.1+ 的显卡
- **CPU 模式**：任意 x64 处理器均可

## 使用方法

1. **解压**到任意文件夹（路径可含中文）
2. 双击 **`CathayOCR Lite.exe`**（或 `启动.bat`）
3. 🎯 简单模式：选择语言 → 点运行
4. 🔧 专业模式：更多参数可调（模型、边长、精度等）
5. 拖放 PDF 文件到列表 → 点运行

## 故障排除

| 问题 | 原因 | 解决 |
|------|------|------|
| GPU 模式黑屏/崩溃 | 显卡驱动过旧 | 更新显卡驱动 |
| AMD 核显高频崩溃 | FP16 加速不稳定 | 切换到 FP32 精度或改用CPU |
| 简单模式 GPU 自动选了 CPU | 未检测到独显 | 手动切换为「独显」 |
| 无法启动 | 安全软件拦截 | 加入信任区或命令行运行查看错误 |
| 语言下拉项是灰色的 | 轻量版字典不覆盖该语种 | 改用专业版，或换覆盖更广的模型 |
| **GPU 跑一阵后大量空白 / 日志反复刷「[自动恢复] 重建引擎」** | Windows TDR 默认只给 GPU 2 秒，超时重置了显卡驱动 | 双击本目录 `GPU卡死修复_调大TDR超时_需重启.reg` 后**重启**；并把「精度」改为 **FP16** |
