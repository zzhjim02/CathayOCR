# CathayOCR Lite (轻量版) v1.3.0

基于 ncnn Vulkan 的便携式 PDF OCR 工具。CathayOCR 专业版的轻量分支。

## 特性亮点

🚀 **单一引擎，一键启动**
- 仅保留 ncnn Vulkan 引擎，无需选择纠结
- GPU 模式（Vulkan 加速）/ CPU 模式（原生 ncnn，不初始化 Vulkan）
- 支持任意品牌显卡：NVIDIA / AMD / Intel 均可
- 支持 PP-OCR 多版本模型（v3 ~ v6）

🪟 **标准软件体验（v1.3.0）**
- 双击 `CathayOCR Lite.exe` 启动，独立日志窗口实时显示运行状态
- 自动清理异常退出遗留的临时文件，C 盘零残留

📦 **极致便携，U 盘即用**
- 自带便携 Python 环境，无需任何安装
- 拷贝到任意目录即可运行

🌍 **多语言支持**

轻量版用 ncnn 的 PP-OCRv6 通用字典，**支持的文字**如下：

| ✅ 支持 | 说明 |
|---|---|
| 中文 | 繁简体自动识别 |
| 英文 / 日文 | 通用字典直接覆盖 |
| 拉丁语系 | Français、Deutsch、Español、Italiano、Português、Nederlands… 40+ 种 |
| 希腊文 | 字典含希腊字符，实测可识别 |
| 多语言混排 | 中·英·日 + 拉丁语系同时排版 |

| ❌ 需专业版 | 原因 |
|---|---|
| 韩文 · 俄文等西里尔文 · 阿拉伯文 · 印地文等天城文 · 泰文 · 泰卢固文 · 泰米尔文 | 通用字典不含这些文字（实测 0 覆盖），轻量版识别会乱码；专业版内置官方分语种模型 |

> 简单模式的语言下拉里，**需要专业版的项已灰显不可选**并在项名后标注「（需专业版）」；✅ 支持 / ❌ 需专业版 的范围写在**下拉的悬停提示**里。

📄 **PDF OCR 专业功能**
- GPU 双实例并行（提升 30~50%）
- 古籍/竖排/复杂排版支持
- 拖放文件处理，批量输出
- 简单模式自动配好全部参数（文档类型 + 精度偏好 + 显卡，显卡可点「🤖 帮我选择」自动检测）

## 系统要求

- **操作系统**：Windows 7/10/11 64位
- **GPU 模式**：支持 Vulkan 1.1+ 的显卡
- **CPU 模式**：任意 x64 处理器均可

## 使用方法

1. 双击 **`CathayOCR Lite.exe`**
2. 先弹出日志窗口（会做一遍硬件自检并给出建议），随后主界面自动出现
3. 🎯 简单模式：选择语言 → 点运行
4. 🔧 专业模式：更多参数可调（模型、边长、精度等）
5. 拖放 PDF 文件到列表 → 点运行

> 🪟 **想边处理边干别的？** 点顶部的「**迷你窗口**」按钮，主界面和日志窗口会一起收成屏幕**右下角**的小卡片（只显示当前处理文件名、已处理 / 总文件数和进度条），识别照常进行。
>
> 处理**完成后会自动还原**；也可以随时点卡片上的「恢复」、双击卡片，或点任务栏图标把它叫回来。卡片标题栏的「📌」可以切换是否**总在最前面**。

## 故障排除

| 问题 | 原因 | 解决 |
|------|------|------|
| GPU 模式黑屏/崩溃 | 显卡驱动过旧 | 更新显卡驱动 |
| AMD 核显高频崩溃 | FP16 加速不稳定 | 切换到 FP32 精度或改用 CPU |
| 主界面迟迟不出现 | 主程序初始化中 | 看日志窗口进度；超过 30 秒关掉重试 |
| 无法启动 | 安全软件拦截 | 加入信任区或用 `启动.bat` 查看错误 |
| 竖排古籍顺序乱 | 未勾选「竖排识别」 | 勾选「OCR 选项」中的「竖排识别」 |
